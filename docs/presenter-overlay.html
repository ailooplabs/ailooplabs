Workflow

How Presenter Overlay works.

Four seamless steps from setup to keynote delivery.

1. Launch & Position

Open Presenter Overlay. Move the semi-transparent HUD right below your webcam or over your presentation window.

2. Start Screen Share

Share your full desktop or application window on Zoom, Teams, or Meet. Cocoa window filtering ensures audience invisibility.

3. Ambient Transcription

Turn on the microphone co-pilot. The engine automatically captures your talking points as live context.

4. Ace The Q&A

When an audience member asks a complex question, type or speak the query to receive instant, fact-checked talking points.

Under The Hood

Modern native architecture.

Lean, auditable, and built with industry-standard technologies.

📦 Tech Stack

  • Tauri v2 Core: Ultra-light native webview container with macOS Cocoa bridging.
  • Rust Backend: Handles native window attributes (NSWindowSharingNone) and system hooks.
  • React 18 + TypeScript: Fast, responsive UI with zero-latency state synchronization.
  • Google Gemini API: Contextual natural language synthesis with low latency.
  • Tailwind CSS: Sleek dark-mode glassmorphic interface with stage contrast presets.
